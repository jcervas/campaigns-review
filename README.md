# Campaigns and Elections review game, Chapters 1–5

Interactive review deck for *Campaigns and Elections* (Sides, Shaw, Grossmann and Lipsitz, 5th ed.).

- Presenter: open the page and choose **Teams on their own computers**.
- Teams: open the join link shown on the main screen and enter the four-letter code.

Live play uses Supabase Realtime (broadcast and presence only; no data is stored).
